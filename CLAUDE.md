### Issue tracker

Issues, tickets and PRDs live in **Linear** (workspace `memoji-inc`, team `MEM`), accessed
via the Linear MCP tools — not GitHub Issues, even though the code is on GitHub.
See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles, unrenamed: `needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, `wontfix` — all already present in Linear team `MEM`.
See `docs/agents/triage-labels.md`.
